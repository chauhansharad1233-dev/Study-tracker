STUDYOS PREMIUM — INSTALLATION FILES

Files:
- index.html: Main premium study tracker app
- manifest.webmanifest: Home-screen installation settings
- sw.js: Service worker for offline/app caching
- icon-192.png and icon-512.png: App icons

GitHub Pages setup:
1. Upload ALL five files to the ROOT of your repository.
2. Ensure the main HTML file is named exactly index.html.
3. In Settings > Pages, select Deploy from a branch, branch main, folder /(root).
4. Open the published Pages URL in Chrome.
5. In Chrome menu, choose Add to Home screen / Install app.

Tracker:
- Start date: 16 November 2026 (Day 1)
- Daily tasks: Maths, GS, English
- Daily scoring is based on task checkboxes: all complete = +1, partial = -0.25, none = -1 per subject.
- Weekly target: 6 full days out of 7 per subject.
- Monthly reports and month-to-month average-point comparison.
- Data is stored locally in this browser/device. Clearing site data can erase it.

Note: This is a new app version with its own local storage key. It will not automatically import data from the older tracker.
